# Programming Cliffnotes

Quick syntax and implementation references for programmers who already understand the underlying concepts but need a refresher when moving between languages and tools.

These examples are not intended to teach programming theory or exhaustively cover every API. They favor small, inspectable reminders of commonly used syntax and patterns.

## Collections

- [`Bash/`](Bash/) — shell scripting examples
- [`Docker/`](Docker/) — basic container examples
- [`Groovy/`](Groovy/) — Groovy syntax examples
- [`HTML-CSS/`](HTML-CSS/) — HTML and CSS examples
- [`Java/`](Java/) — Java syntax examples
- [`JavaScript/`](JavaScript/) — vanilla JavaScript examples
- [`Python3/`](Python3/) — Python 3 syntax examples
- [`Ruby/`](Ruby/) — Ruby syntax examples

Framework- and library-specific examples live in [`../frameworks/`](../frameworks/).
