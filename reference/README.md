# Reference

Curated, reusable examples that serve as this repository's canonical implementation or syntax reference for a subject.

Reference material should:

- have a clear and narrow purpose;
- be understandable without reconstructing an old experiment;
- favor readable examples over production-scale architecture; and
- include source attribution where it builds on external material.

## Collections

- [`algorithms/`](algorithms/) — classic algorithms and data structures
- [`frameworks/`](frameworks/) — framework and library reference projects
- [`interview-prep/`](interview-prep/) — programming interview exercises
- [`programming-cliffnotes/`](programming-cliffnotes/) — language, syntax, and foundational tooling examples

Unfinished investigations belong in [`../scratch/`](../scratch/). Work tied primarily to a book, tutorial, or course belongs in [`../learning/`](../learning/).
