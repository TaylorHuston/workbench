# Learning

Exercises, notes, and follow-along projects created from books, tutorials, and courses.

IMPORTANT: As the content in here is meant for learning it should all be coded by hand. No direct LLM assistance, outside of possibly basic IDE autocomplete, is allowed. Review and advice can be.

## Structure

- [`books/`](books/) — book exercises and companion work
- [`courses/`](courses/) — structured course material
- [`tutorials/`](tutorials/) — documentation and web tutorial projects
- [`youtube/`](youtube/) — tutorial projects grouped by creator or channel

Preserve the source, author, and relevant licensing information in each project's README. A project can move to [`../reference/`](../reference/) when it has been deliberately reshaped into a maintained canonical example rather than remaining a record of the source-led learning process.
